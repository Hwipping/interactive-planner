영상 편집 · 썸네일 기획안

짧게 적고, 편집하면서 바꿔도 괜찮아요.

주제 → 사용할 자료 → 편집 느낌 → 음악 → 썸네일 순서로 생각해 보세요. 필요 없는 칸은 비워두고, 정하지 못한 내용은 ‘미정’으로 적어도 됩니다.

입력 내용은 자동 저장됩니다. 나가기 전 상단의 ‘저장 완료’를 확인하세요.
